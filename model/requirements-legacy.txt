# Pinned environment for reproducing the CGMacros reference notebook
# (parse_data.ipynb, from https://github.com/PSI-TAMU/CGMacros).
#
# WHY THIS EXISTS
# ---------------
# The reference notebook does not run on a modern Python stack. It calls
# DataFrame.append (removed in pandas 2.0) and np.trapz (deprecated in NumPy 2).
# Reproducing the published baseline therefore needs the original pins, not a
# port -- a port would be a re-implementation, and any difference from the
# paper's numbers would be unattributable.
#
# PYTHON VERSION IS NOT OPTIONAL: 3.8.
# numpy 1.18.4 was released May 2020, before Python 3.9 existed, so there is no
# cp39 wheel for it and no supported build path on Windows. Verified by probing
# the index: every other pin here has a cp39 wheel; numpy 1.18.4 does not.
# Install the interpreter with:  uv python install 3.8
#
# These are the CGMacros repo's own pins, copied verbatim.
matplotlib==3.4.2
numpy==1.18.4
pandas==1.3.5
scikit-learn==0.24.2
scipy==1.5.2
shap==0.42.1
statsmodels==0.13.5
xgboost==1.6.2

# The upstream file also pins `pip==22.3.1`. Left out deliberately: pinning pip
# inside its own requirements file is a bootstrapping quirk, not a dependency
# of the analysis. Add it back if a resolution difference ever shows up.

# Needed to execute the notebook; not part of the upstream pin set.
# Deliberately NOT `notebook`: on Python 3.8 it pulls terminado -> pywinpty,
# whose build backend (puccinialin) requires >=3.9, so the install dies on a
# dependency that has nothing to do with the analysis. nbconvert --execute
# runs the notebook headlessly with just ipykernel, which is all we need.
ipykernel
nbconvert
